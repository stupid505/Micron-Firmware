# Micron-Firmware
DISCLAIMER: THIS FIRMWARE/OS IS ONLY FOR THE M5 CARD COMPUTER ORIGIONAL/ADV.
AND PLEASE PRONOUNCE IT AS "Mike-Ron".

# Requirements (As A Whole)
7MB+ Of Built In Storage (Not Including Micro SD Card),
64GB+ Micro SD Card (Sandisk Reccomended) (If You Dont Have A SD Then There Is Still A Workaround),
A Computer/Laptop With A USB-A Port,
A USB-A To USB-C Cable,
"M5 Burner" Installed to Said Computer/Laptop.

# Getting Started
Micron may be tricky to install. This will guide you!

1. Open "M5 Burner" on you're Computer/Laptop.
(Make sure you are signed into a account. if not, make one.)
2. At the top, search up "Micron".
3. Click download.
(After this point make sure you have you're cardputer in install mode connected to your pc/laptop)
4. Then click "Burn"
5. Not you will see the burning page. Click Erase to erase all of the connected cardputer's contents. (This makes of room for micron)
6. Then once you are done with erasing go back to the burning page and click Start.
7. Now when you have waited for it to be done click the green button.
Now you can turn the cardputer on and continue to the next part.

# Choosing A Edition
In total micron has 3 diffrent editions of micron. Micron Classic, Micron Lite, And MicronCyber Atks.

1. Power On the cardputer (Or off then on)
2. you will see the 3 editions of micron labeled in diffenent keys.
3. Choose a edition based on you're needs, likings, ect. (if you need more help then go to the main branch and go to "Help editions")
4. Press the keybutton for you're desired edition.
5. now enter your wifi SSID/Name & wifi PSWD/password using keybuttons, enter, delete, ect.
Then it will surf the web and try and download your edition you chose via raw github user content, save it, and restart to enter micron.
