# Micron-Firmware
DISCLAIMER: THIS FIRMWARE/OS IS ONLY FOR THE M5 CARD COMPUTER ORIGIONAL/ADV.

# Requirements (As A Whole)
7MB+ Of Built In Storage (Not Including Micro SD Card),
64GB+ Micro SD Card (Sandisk Reccomended),
A Computer/Laptop With A USB-A Port,
A USB-A To USB-C Cable,
"M5 Burner" Installed to Said Computer/Laptop.
